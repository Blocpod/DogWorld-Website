# DOG•WORLD

A cinematic, community-built concept site for DOG•GO•TO•THE•MOON on Bitcoin.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Import `Blocpod/DogWorld-Website` into Vercel.
2. Keep the detected framework set to **Next.js**.
3. Use the default build command, `npm run build`.
4. Deploy. No environment variables, database, authentication provider, or user account is required.

## Production commands

```bash
npm run lint
npm run build
npm start
```

## Access

The website is public by design. It contains no login flow, access middleware, authenticated routes, or private hosting configuration.
